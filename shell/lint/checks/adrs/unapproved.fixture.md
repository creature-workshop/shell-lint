# ADR.7: Work arrives as fragments

- Status: proposed
- Date: 2026-01-01
- Merge request: https://example.com/org/tool/-/merge_requests/1
- Implementation: not started

## Context

A change is reviewed in pieces, and a piece is not always shippable alone.

## Decision

A piece of review is a fragment, as
[ADR.3@tool](../000003-the-trunk-moves-once/adr.md) already assumes. An example
is free to show the bare form:

```
See ADR.3@tool, or tool ADR 3.
```
